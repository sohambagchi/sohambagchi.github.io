Vertical timeline drawn as one continuous thread with nodes; use for an About page, a CV, or a project's history.

```jsx
<Timeline items={[
  { year: 'Now', title: 'Independent', place: 'Lisbon', current: true },
  { year: '2019–24', title: 'Design lead', place: 'A small studio', body: 'Books, maps, and the tools around them.' },
]} />
```
