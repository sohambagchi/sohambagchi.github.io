Circular icon-only button; use for compact actions like close, theme toggle, menu, or prev/next.

```jsx
<IconButton icon="x" label="Close" />
<IconButton icon="moon" label="Ink theme" variant="outline" />
<IconButton icon="arrow-right" label="Next" variant="solid" size="lg" />
```

- Always pass `label`. `solid` turns cinnabar on hover.
