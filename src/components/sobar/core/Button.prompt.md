Pill-shaped action button with a left-to-right fill wipe on hover; use for any primary or secondary action.

```jsx
<Button arrow>See the work</Button>
<Button variant="accent" icon="mail">Write to me</Button>
<Button variant="secondary" size="sm">Read more</Button>
<Button variant="ghost" icon="download">CV</Button>
```

- `primary` (ink) is the default; reserve `accent` (cinnabar) for one moment per view.
- `arrow` adds a trailing arrow that drifts forward on hover — use for navigation.
- `href` renders an anchor with identical styling.
